옵션

공백 무시
모든 공백 문자(탭, 줄 끝 CR 포함)를 지우고 비교합니다(GNU -w 상당). 화면에는 원문이 보입니다.
대소문자 무시
소문자로 바꿔 비교합니다(GNU -i 상당).
빈 줄 무시
추가·삭제된 줄이 전부 빈 줄인 변경은 "무시됨"으로 흐리게 표시하고 통계·이동·접기에서 뺍니다. 공백 무시가 켜져 있으면 공백만 있는 줄도 빈 줄로 봅니다.
컨텍스트
변경 앞뒤로 보여 줄 줄 수입니다. patch의 컨텍스트 줄 수도 같습니다.

patch

GNU diff -u 형식입니다. 무시 옵션이 켜져 있으면 컨텍스트 줄은 왼쪽 원문으로 쓰이고, 무시된 차이는 patch에 반영되지 않습니다. 무시된 빈 줄 변경이 다른 변경과 가까이(컨텍스트 2배 이내) 있으면 같은 hunk 안에 +/-로 함께 나옵니다.

알아둘 점

  • 줄은 \n으로만 나눕니다. 옵션 없이 CRLF 파일과 LF 파일을 비교하면 모든 줄이 다르게 나옵니다(공백 무시를 켜면 같아집니다). 변경된 줄에서는 \r이 ␍로 보입니다.
  • 파일 끝 개행 유무가 다르면 마지막 줄은 항상 다른 줄로 봅니다(GNU diff와 같음).
  • 서로 많이 다른 큰 입력은 계산 시간을 제한하려고 최소 diff가 아닐 수 있습니다(결과는 여전히 정확). 이때 결과 위에 배지가 표시됩니다. 약 2만 줄 이하는 항상 최소 diff입니다.
  • 파일은 UTF-8로만 읽고 BOM은 그대로 비교합니다. 앞 8KB에 NUL 바이트가 있는 파일은 바이너리로 보고 비교하지 않습니다.
  • 브라우저 입력 칸은 붙여넣은 텍스트의 \r을 지웁니다. CRLF를 그대로 비교하려면 파일 열기나 끌어다 놓기를 쓰세요.
  • 모든 처리는 이 페이지 안에서만 이루어지며 아무것도 전송하거나 저장하지 않습니다.
